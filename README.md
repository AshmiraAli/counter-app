# Counter App (Increment Web App)

A simple JavaScript-based counter web application that allows users to increment a count and save previous entries. This project is built using **HTML, CSS, and JavaScript** without any backend.

## 📌 Features

- Save previous counts
- Display history of saved entries
- Clean and simple UI
- Beginner-friendly project
